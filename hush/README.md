# 嘘 ——（hush v2）

给「主人」用的群静音插件。**纯插件实现，不改任何核心代码。**

## 指令

格式：`@她 <静音指令> [档位] [时长]`，只有主人（`ownerQq`）发的才算。

| 指令 | 效果 |
|---|---|
| `/静音 30` | 默认档（只回艾特）30 分钟 |
| `/静音 完全 30` | **完全不说话**：连 @ 也不回，插件在 `before-tool` 里硬拦发送 |
| `/静音 睡觉 8小时` | 完全不说话，标记为"睡觉"；解除时若有人叫过她会主动问一句 |
| `/静音 礼貌 30` | 被 @ 时只回**一句**很短的礼貌话，有冷却（默认 10 分钟一次） |
| `/静音 0` | 一直静音，直到 `/说话` |
| `/说话` | 解除，并把静音期间的账**汇报**给她 |

时长写法：`30`、`30分`、`90秒`、`2小时`、`半小时`；上限 `maxMinutes`（默认 720 = 12 小时）。

## 静音记账（v2 新增）

静音期间，插件会记录这个群：

- 来了多少条消息
- 有几次在 @ 她

`/说话` 解除时，这些数字会被塞进她这一轮的上下文，让她用自己的口气说一句，例如：

> "我回来了。刚刚 23 分钟群里聊了 41 条，有 3 次在叫我。"

而不是冷冰冰的报表。数字存在 `data/hush-state.json`。

## 四个档位

| 档位 | 核心层 | 插件层 |
|---|---|---|
| `atOnly` | 档位锁成 1（只回 @） | 不干预 |
| `silent` | 同上 | 注入"别说话" + 拦 `send_message`/`send_to`/`send_sticker`/`send_poke` |
| `sleep` | 同上 | 同 silent，解除时多问一句"刚才有人叫我？" |
| `polite` | 同上 | 被 @ 且过冷却 → 只回一句礼貌话；否则沉默 |

> 说明：核心只提供"1 档"这一种强度，所以 `silent` 是"照常被唤醒、但插件把嘴捂住"。模型仍会被调用（省不了 token），但一条也发不出去。

## 实现原理（为什么不用改核心）

```
hush 写 config.commandMute.active[群号] = 到期时间戳
核心 config.js: storeConfigForChat() → commandMuteTier() 命中 → contextTier=1、randomPercent=0
```

即在核心看来这就是普通的"指令禁言"，插件在此基础上用钩子补足强度与记账。

钩子分工：

- `before-context`：认指令 / 记账 / 判断这轮该不该出声
- `before-llm-messages`：把"闭嘴"或"汇报"的指令追加到请求末尾
- `before-tool`：静音期硬拦发送类工具

## 已知边界

1. **只作用于群**，私聊不受影响（`/静音` 在私聊里会被忽略）
2. **拦不住语音插件**：`/语音` 是 voice 插件自己走 OneBot HTTP 发的，不经过工具层。要完全静音需要同时在 voice 插件里禁用它
3. **和核心自带 `/安静` 共用同一个 `commandMute.active`**，两者会互相覆盖
4. **主动行为不受控**：`her-life` / `feed-scroller` 的主动私聊和分享照发（静音只压"回复"，不压"主动"）
