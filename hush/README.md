# 🤫 嘘 ——（hush v2）

> 群里太吵时，让主人一键闭上她的嘴。

给 QQ Agent 用的**群静音**插件。纯插件实现，**不改任何核心代码**，QQ Agent 升级不会冲掉。

```text
@她 /静音 完全 30      → 这个群半小时内她一句话都不说
@她 /说话              → 恢复，并汇报"刚刚 23 分钟里群里聊了 41 条，有 3 次在叫我"
```

---

## ✨ 特性

- 🎚 **四档强度** —— 只回@ / 完全不说话 / 睡觉 / 只回一句礼貌话
- ⏱ **灵活时长** —— `30`、`90秒`、`2小时`、`半小时`、`0`（一直静音）
- 📊 **静音记账** —— 期间来了多少条、被点名几次，解除时用自己的口气汇报
- 🙅 **硬拦截** —— `silent` / `sleep` 档直接拦 `send_message` 等发送工具，不是靠"求模型别说话"
- 🛟 **状态持久化** —— 存在 `data/hush-state.json`，重启不丢
- 🔒 **只认主人** —— 别人发指令一律无效

## 📖 指令

格式：`@她 <静音指令> [档位] [时长]`

| 指令 | 档位 | 效果 |
|:---|:---|:---|
| `/静音 30` | `atOnly` | 只回 @，30 分钟后自动恢复 |
| `/静音 完全 30` | `silent` | **完全不说话**，连 @ 也不回 |
| `/静音 睡觉 8小时` | `sleep` | 同 silent，解除时若有人叫过她会问一句 |
| `/静音 礼貌 30` | `polite` | 被 @ 只回一句"我先安静会儿"，有冷却 |
| `/静音 0` | — | 一直静音，直到 `/说话` |
| `/说话` | — | 解除 + 汇报 |

**时长写法**：`30` / `30分` / `90秒` / `2小时` / `半小时`；上限 `maxMinutes`（默认 720 分钟 = 12 小时）。

**档位同义词**：`完全`/`彻底`/`闭嘴`/`闭麦`、`睡觉`/`睡眠`、`礼貌`/`婉拒`、`仅艾特`/`常规`。

## 🎚 四档到底怎么实现

核心只提供"1 档（只回 @）"这一种强度，剩下的由插件在钩子里补：

| 档位 | 核心层（`commandMute`） | 插件层 |
|:---|:---|:---|
| `atOnly` | 档位锁成 1 | 不干预 |
| `silent` | 同上 | 注入"别说话" + `before-tool` 拦发送工具 |
| `sleep` | 同上 | 同 silent，另存"睡觉"语义用于解除时的追问 |
| `polite` | 同上 | 被 @ 且过冷却 → 只回一句礼貌话；否则沉默 |

> `silent` 的本质是「**照常被唤醒，但插件把嘴捂住**」。模型仍会被调用（省不了 token），但一条也发不出去。

## 🧠 工作原理

```text
                      ┌──────────────────────────────┐
主人: /静音 完全 30 ──► │ before-context               │
                      │  ① 认指令（群 + 主人 + 解析） │
                      │  ② 写 config.commandMute     │──► 核心此后把该群锁成 1 档
                      │  ③ 写 data/hush-state.json   │──► 档位 / 到期 / 记账
                      │  ④ 暂存"确认台词"给模型       │
                      └──────────────────────────────┘
                                    │
群友: @她 在吗 ──────► before-context：记账（+1 条 / +1 次点名）
                             └─ 若 silent → 暂存 { block: true }
                                    │
                      before-llm-messages：把"这轮别说话"追加到请求末尾
                                    │
                      before-tool：send_message 等 → { block: true }  ← 嘴被捂住
```

**为什么能不用改核心**：核心的 `storeConfigForChat()` 每次消息都会读 `commandMute.active[群号]`，命中就把 `contextTier` 强制成 1、`randomPercent` 归零。对它来说这只是一次普通的"指令禁言"。

## 📊 静音记账

静音期间按群累计：

| 字段 | 含义 |
|:---|:---|
| `msgs` | 期间来了多少条消息 |
| `ats` | 有几次在 @ 她 |
| `startedAt` | 静音开始时间（用于算"静音了多久"） |
| `mode` | 当时的档位 |
| `until` | 到期时间戳（`0` = 手动解除） |
| `politeAt` | 礼貌档上次回应的时刻（用于冷却） |

存储位置：`data/hush-state.json`（可用 `stateFile` 改）

```json
{
  "groups": {
    "479280340": {
      "until": 1792934400000,
      "mode": "silent",
      "startedAt": 1792932600000,
      "msgs": 41,
      "ats": 3,
      "politeAt": 0
    }
  }
}
```

解除时这些数字会被塞进她这一轮的上下文，让她用自己的口气说，例如：

> "我回来了。刚刚 23 分钟群里聊了 41 条，有 3 次在叫我。"

而不是冷冰冰的报表 —— 提示词里明确要求"可以提数字，但别像报表、别列清单"。

## ⚙️ 配置项

| 键 | 默认 | 说明 |
|:---|:---|:---|
| `enabled` | `true` | 总开关 |
| `ownerQq` | — | 主人 QQ；留空回落到「主人识别」插件 |
| `quietCommand` | `/静音` | 静音指令 |
| `resumeCommand` | `/说话` | 解除指令 |
| `defaultMode` | `atOnly` | 不写档位时用哪个 |
| `politeCooldownMin` | `10` | 礼貌档冷却（分钟） |
| `defaultMinutes` | `30` | 只说 `/静音` 时用 |
| `maxMinutes` | `720` | 上限，防止手滑输入 9999 |
| `stateFile` | 空 | 留空 = `data/hush-state.json` |

## ⚠️ 已知边界

| # | 边界 | 说明 |
|:--|:---|:---|
| 1 | **只作用于群** | 私聊里 `/静音` 会被忽略（设计如此） |
| 2 | **拦不住语音** | `/语音` 是 voice 插件自己走 OneBot HTTP 发的，不经过工具层。要在静音期连语音一起禁，得两个插件联动 |
| 3 | **和核心自带 `/安静` 共用一个字段** | 都写 `commandMute.active`，两条指令会互相覆盖 |
| 4 | **压不住主动行为** | `her-life` 的主动私聊、`feed-scroller` 的群内分享照发 —— 静音只压"回复"，不压"主动" |
| 5 | **模型仍会被调用** | `silent` 只是把嘴捂住，token 照烧 |

## 🔧 故障排查

| 现象 | 原因 | 处理 |
|:---|:---|:---|
| 指令没反应 | `config.commandMute.enabled` 不是 `true` | 日志里会打"静音指令未生效"，去配置打开 |
| 非主人发的也生效 | `ownerQq` 写错/为空且「主人识别」没配 | 检查两处 |
| 静音不解除 | `until` 是 `0`（手动解除模式） | 发 `/说话` |
| 状态文件丢了 | `stateFile` 指向不可写路径 | 日志会有"写 hush 状态失败" |
| 她还在说话 | 档位是 `atOnly`（只回 @）或被人点名 | 用 `/静音 完全` |

## 🧪 自测

`index.js` 导出 `internals`，可脱离运行环境直接打：

```js
import * as hush from './index.js';
hush.internals.parseCommand('/静音 完全 30');   // → { kind:'quiet', mode:'silent', ms:1800000 }
hush.internals.decide({ chatKey:'group:123', triggerEntries:[{ senderId:'2421954183', text:'/静音 30' }] });
hush.internals.readState({});                   // 读状态文件
```

当前测试覆盖 19 项（指令解析 6 / 权限 3 / 端到端 8 / 礼貌档冷却 2），全通过。
